# ADR-0001 — Projekta identitāte

**Datums:** 2026-09-30
**Statuss:** Pieņemts

## Konteksts

Projektam nepieciešams stabils nosaukums, avota failu paplašinājums un CLI identitāte.

## Lēmums

- Projekta nosaukums: **LatNe**
- Avota paplašinājums: **`.lat`**
- CLI: **`latne`**

## Sekas

Visi turpmākie publiskie nosaukumi, dokumentācija un tooling tiek būvēti ap šo identitāti.

Vizuālais zīmols vēl nav noslēgts un var attīstīties neatkarīgi no tehniskās identitātes.
