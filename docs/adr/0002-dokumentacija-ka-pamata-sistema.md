# ADR-0002 — Dokumentācija kā pamata sistēma

**Datums:** 2026-09-30
**Statuss:** Pieņemts

## Konteksts

LatNe paredzēts kā ilgtermiņa projekts ar daudz valodas, compiler un tooling lēmumiem. Commit vēsture viena pati nesaglabā pietiekamu kontekstu.

## Lēmums

Dokumentācija ir pirmās klases projekta sastāvdaļa.

Tiek uzturēti:
- hronika;
- tehniskais žurnāls;
- ADR;
- kļūdu un atklājumu reģistrs;
- aktuālais statusa fails;
- terminoloģijas politika.

## Sekas

Nozīmīgs darbs nav pilnībā pabeigts, kamēr nav atjaunota tam atbilstošā dokumentācija.
